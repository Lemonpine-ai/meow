# VoiMeow 챗봇

OpenAI API를 활용한 VoiMeow 고객센터 챗봇입니다.

## 설치 방법

1. 프로젝트 디렉토리에서 다음 명령어를 실행하여 필요한 패키지를 설치합니다:

```bash
npm install
```

2. 개발 서버를 실행합니다:

```bash
npm run dev
```

3. 브라우저에서 표시되는 로컬 주소(예: http://localhost:5173)로 접속합니다.

## 주요 기능

- **실시간 대화**: OpenAI GPT-3.5-turbo 모델을 사용한 자연스러운 대화
- **대화 기록 유지**: 이전 대화 내용을 기억하여 문맥에 맞는 답변 제공
- **사용자 친화적 UI**: 직관적이고 아름다운 채팅 인터페이스
- **로딩 인디케이터**: AI가 응답을 생성하는 동안 시각적 피드백 제공

## 파일 구조

- `index.html` - 메인 HTML 파일
- `chatbot.js` - 챗봇 JavaScript 로직
- `chatbot.css` - 챗봇 스타일링
- `script.js` - 기존 사이트 스크립트

## 주의사항

현재 코드에는 OpenAI API 키가 하드코딩되어 있습니다. 프로덕션 환경에서는 환경 변수를 사용하여 API 키를 안전하게 관리해야 합니다.
